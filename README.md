# Bangla News Hub

A modern and responsive Bangla news website built with Next.js. **Bangla News Hub** provides a clean and user-friendly platform for browsing the latest Bangla news across different categories.

## 🌐 Live Website

🔗 [https://newshub-bangla.vercel.app/](https://newshub-bangla.vercel.app/)

## 📖 About The Project

Bangla News Hub is a modern news platform designed to present Bangla news in a simple, readable, and responsive interface. The website focuses on providing a smooth browsing experience with categorized news, featured stories, detailed articles, and a clean editorial design.

## ✨ Key Features

- 📰 **Latest News** — Browse the latest published news and updates.
- 🔥 **Featured News** — Highlight important and trending stories.
- 🗂️ **News Categories** — Explore news based on different categories.
- 📄 **News Details** — Read complete articles with descriptions and publication information.
- 🔐 **User Authentication** — Secure sign-up and login functionality powered by Better Auth.
- 👤 **User Accounts** — Users can create and manage their accounts.
- 📱 **Responsive Design** — Optimized for mobile, tablet, and desktop devices.
- ⚡ **Fast Performance** — Built with Next.js for optimized performance.
- 📅 **Bangla Date & Time** — Displays publication dates and times using Bangla localization.
- 🎨 **Interactive UI** — Smooth hover effects and modern card-based layouts.
- 🧭 **Clean Navigation** — Easy navigation between news categories and important pages.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/amitpauldev/bangla-news-hub/
```

### 2. Navigate to the project

```bash
cd bangla-news-hub
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the project.

## 📦 Build for Production

```bash
npm run build
```

To start the production server:

```bash
npm start
```
